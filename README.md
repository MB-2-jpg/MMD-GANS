# DEMYSTIFYING-MMD-GANS
The goal of the project is to  implement and analyse the performance , limits of a method of improving the stability of the GAN's training:  Using an MMD as a critic.mentations décrites dans les papiers existants)
analysis with a quantitative result in the case of a kernel of the form $k(x,y)= f(||x-y||^2)$.
Adding an example of current generator's images trained on CIFAR.
